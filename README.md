# GOIGOX Cabs

Website for [irfantaxi.in](https://irfantaxi.in/) — **GOIGOX Cabs** (also known as Irfan Taxi): GOI & GOX airport transfers, local sightseeing, and outstation trips in Goa.

Built with **Next.js 16**, **React 19**, and **Tailwind CSS 4**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Pages

- `/` Home
- `/services` Airport, sightseeing, outstation
- `/fleet` Cars and comparison
- `/pricing` Per-km rates
- `/routes` Fixed fares and calculator
- `/goa` Beaches, churches, tours
- `/faq` Questions
- `/reviews` Guest stories
- `/book` WhatsApp booking form

Bookings open WhatsApp at **+91 80889 43818**. Deploy the `src` app to Vercel or any Node host, then point the domain to it.
